# One Line, One Laugh

One original funny line for the
[One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3)
bounty: a standing desk bought for health, used for sitting.

> I bought a standing desk to be healthier; now I sit on it.

Ten candidates were drafted in [CANDIDATES.md](CANDIDATES.md); this one won
on surprise (the setup promises virtue, the punchline defeats the desk's
whole purpose in five words), economy (58 characters), and freshness.

## Run

```sh
python3 main.py
```

Writes the line to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
